What gets checked

A typical uptime probe resolves the name once, hits one address, and reports green. With 47-day certificates (and Let’s Encrypt’s 6-day ones) a node that missed the reload is a weekly chance, not a yearly accident.

checkone-IP probecertfanhow
Every A and AAAA addressresolved by default, or pass backends with --connect 10.0.0.7:443
TLS handshake per address, right SNIchain and hostname verified, served certificate kept
Fingerprints compared across nodesthe odd one out fails, named by address
Expiry warninglast days, or last third of the certificate’s lifetime, on every node

One command

Python 3.9+, no dependencies. Exit codes drop straight into cron, CI or a Kubernetes CronJob.

$ certfan check shop.example.com
shop.example.com  4 address(es), 2 distinct certificate(s)
  PASS  203.0.113.10   cert A  expires 2026-11-20  TLSv1.3  41ms
  PASS  203.0.113.11   cert A  expires 2026-11-20  TLSv1.3  38ms
  FAIL  203.0.113.12   cert B  expires 2026-10-12  TLSv1.3  44ms
    - 203.0.113.12: serves a different certificate than the other nodes
  PASS  2001:db8::10   cert A  expires 2026-11-20  TLSv1.3  40ms
  verdict: FAIL   exit 2
